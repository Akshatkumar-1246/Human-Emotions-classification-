# Human-Emotions-classification-

A machine learning project that classifies human emotions from text using Natural Language Processing (NLP). The model analyzes written sentences and predicts the emotion expressed in them.

## Goal
The goal of this project is to understand how machine learning and NLP techniques can be used to recognize human emotions from textual data.


## Overview

This project uses **TF-IDF (Term Frequency–Inverse Document Frequency)** for converting text data into numerical features and **Multinomial Naive Bayes** as the classification algorithm. It focuses on building a simple, fast, and effective emotion detection system.

## Features

- Text preprocessing and cleaning  
- Feature extraction using TF-IDF  
- Emotion prediction from user input  
- Lightweight and efficient ML model  
- Easy to train and test

## Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- NLP (Natural Language Processing)

##  Model Workflow

1. Load emotion-based text dataset  
2. Clean and preprocess text data  
3. Convert text into vectors using TF-IDF  
4. Train Multinomial Naive Bayes classifier  
5. Predict emotions for new text inputs  

##  Algorithm

- **Feature Extraction:** TF-IDF Vectorizer  
- **Classifier:** Multinomial Naive Bayes
